Project Name: URL-Shortner

Project Decription: URL shortner project where we can create a short url for long urls.

----Tech Stack-----
|-React.js
|-Vite
|-Node.js
|-Express.js
|-REST API
|-PostgreSQL
|-Docker
|-Docker Compose
|-GitHub Actions
|-Git & GitHub

-----Folder Structure-----
|-Frontend
|-Backend
|-.gitignore
|-docker-compose.yml
|-.github
|-README.md



----Setup Project-----
 git clone "https://github.com/mayankrwt0028/Url-shortner.git"

-Frontend:

cd frontend npm install

-Backend:

cd backend npm install

----Run the Application with Docker--- -Build and start the containers:

docker compose up --build
